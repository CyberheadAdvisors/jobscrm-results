# jobscrm-results
Public copy of the scan results from the private JobsCRM repo, written by its GitHub Actions
workflows (careers-scan.yml, portfolio-refresh.yml). All data comes from public job boards.
Files: results/careers-latest.json, ats-updates.json, portfolio-refresh.json and the
log-github-*-latest.json run logs. Do not edit by hand; each run overwrites it.
